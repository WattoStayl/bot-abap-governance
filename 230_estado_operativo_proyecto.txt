ESTADO
El experimento de Agent Builder con gobernanza pública en GitHub/GitHub Pages queda PAUSADO por instrucción humana. La publicación permanece disponible y la indexación pública puede continuar, pero no se realizarán nuevas acciones sobre ese experimento hasta decidir retomarlo.

La gobernanza pública sigue siendo exclusivamente experimental. No está autorizado almacenar operación real aquí.

Se registra como siguiente línea experimental un agente sin dependencia de GitHub para el estado operativo, basado en documentación canónica administrada por el humano:
- 1 ticket = 1 archivo Markdown canónico;
- 1 proyecto = 1 archivo Markdown canónico;
- el humano carga el archivo para iniciar o retomar trabajo;
- al pausar, cambiar de trabajo o terminar, el agente devuelve el archivo actualizado para custodia humana;
- análisis cross pueden usar varios archivos, en solo lectura por defecto, y producir informes en el formato solicitado.
